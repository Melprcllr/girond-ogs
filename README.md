# Girond'ogs 🐾

**Discover dog-friendly walking spots in Gironde (33), France.**

Girond'ogs is a full-stack web application designed to help dog owners discover and explore walking spots in Gironde, with practical information to choose locations adapted to their dogs' needs.

## 🎯 Project goals

The goal is to provide a platform where dog owners can find suitable walking locations based on their preferences, their dog's needs and potential environmental or regulatory risks.

## ✨ Features

### Planned features

- **Interactive map:** Explore walking spots through an interactive map.
- **Search:** Find walking locations by address, city or location.
- **Advanced filters:** Filter spots by environment, distance, shade, water access and other criteria.
- **Safety information:** Identify potential risks such as pine trees, processionary caterpillars, farm animals and stagnant water.
- **Dog-friendly information:** Check leash requirements, dog access restrictions and local regulations.
- **Detailed location pages:** Access practical information about each walking spot.
- **Favorites:** Save preferred locations using local storage.
- **GPS navigation and sharing:** Get directions to a walking spot and share its location.

## 🏗️ Architecture

The project follows a separated frontend/backend architecture:

- The frontend handles the user interface and interactions.
- The backend exposes a REST API and handles business logic.
- PostgreSQL stores walking locations and their associated information.
