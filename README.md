
# Girond'ogs 🐾

**A full-stack, map-first and mobile-first web application to discover dog-friendly walking spots across Gironde, France.**

# English

## 🎯 Project goals

Girond'ogs is a full-stack web application designed to help dog owners discover walking spots across Gironde (33), France.

The platform provides practical information about each location, helping users find places that match their preferences and their dogs' needs while taking environmental risks and local regulations into account.

## ✨ Features

### Planned features

- **Interactive map:** Explore dog-friendly walking spots through an interactive map.
- **Search:** Find locations by Gironde municipality or postal code.
- **Advanced filters:** Combine multiple criteria to find suitable locations based on their environment and available features.
- **Environment information:** Identify different environments such as forests, vineyards, beaches, shaded areas and water access.
- **Safety information:** Identify potential risks such as pine trees, processionary caterpillars, farm animals and stagnant water.
- **Dog access regulations:** Check leash requirements, dog access restrictions and local regulations.
- **Location details:** Access practical information about each walking spot.
- **Favorites:** Save preferred locations for easy access.

## 🏗️ Architecture

The project follows a separated frontend/backend architecture:

- **Frontend:** Handles the user interface, map interactions, search and filtering.
- **Backend:** Exposes a REST API and handles business logic.
- **Database:** Stores walking locations and their associated information.

# Français

## 🎯 Objectifs du projet

Girond'ogs est une application web full-stack conçue pour aider les propriétaires de chiens à découvrir des lieux de balade en Gironde (33).

La plateforme propose des informations pratiques sur chaque lieu afin de permettre aux utilisateurs de trouver des endroits adaptés à leurs préférences et aux besoins de leurs chiens, tout en tenant compte des risques environnementaux et des réglementations locales.

## ✨ Fonctionnalités

### Fonctionnalités prévues

- **Carte interactive :** Explorer les lieux de balade adaptés aux chiens grâce à une carte interactive.
- **Recherche :** Trouver des lieux par commune ou code postal de Gironde.
- **Filtres avancés :** Combiner plusieurs critères pour trouver des lieux correspondant à ses préférences et à ses besoins.
- **Informations sur l'environnement :** Identifier les différents environnements comme les forêts, les vignes, les plages, les zones ombragées et les points d'eau.
- **Informations de vigilance :** Identifier les risques potentiels comme les pins, les chenilles processionnaires, les animaux d'élevage et les eaux stagnantes.
- **Réglementation canine :** Consulter les obligations de tenue en laisse, les restrictions d'accès aux chiens et les réglementations locales.
- **Fiches des lieux :** Accéder aux informations pratiques de chaque lieu de balade.
- **Favoris :** Enregistrer ses lieux préférés pour les retrouver facilement.

## 🏗️ Architecture

- **Backend :** Expose une API REST et gère la logique métier.
- **Base de données :** Stocke les lieux de balade et les informations qui leur sont associées.
